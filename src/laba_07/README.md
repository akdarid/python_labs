# Лабораторная работа №7 — Консольное приложение

## 1. Цель работы

Цель лабораторной работы — объединить знания, полученные в ЛР1–ЛР6, в одно работающее консольное приложение.

В рамках работы было реализовано интерактивное CLI-приложение для управления банковскими счетами.

В приложении используются:

- классы и инкапсуляция;
- наследование;
- полиморфизм;
- коллекции объектов;
- функции как аргументы;
- стратегии сортировки;
- собственные исключения;
- сохранение и загрузка данных из JSON-файла;
- типизация;
- разделение кода на модули и слои.

Предметная область осталась прежней — банковская система.  
В приложении используются банковские счета:

- накопительный счёт;
- кредитный счёт.

## 2. Структура проекта

Структура лабораторной работы:

```text
src/
├─ lab07/
│  ├─ README.md
│  ├─ main.py
```

### Назначение файлов

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа в приложение. Запускает CLI-приложение. |
| `cli.py` | Отвечает за консольное меню, ввод данных пользователем и вывод информации на экран. |
| `app.py` | Содержит бизнес-логику приложения: добавление, удаление, поиск, фильтрацию и сортировку счетов. |
| `exceptions.py` | Содержит собственные исключения приложения. |
| `storage.py` | Отвечает за сохранение и загрузку данных из JSON-файла. |
| `accounts.json` | Файл с сохранёнными банковскими счетами. Создаётся автоматически после сохранения. |
| `README.md` | Описание лабораторной работы и демонстрация работы программы. |

## 3. Описание CLI

Приложение запускается командой:

```bash
python main.py
```

После запуска пользователь видит консольное меню:

```text
==================================================
МЕНЮ
==================================================
1. Добавить накопительный счёт
2. Добавить кредитный счёт
3. Показать все счета
4. Найти счёт по номеру
5. Показать только активные счета
6. Фильтр по валюте
7. Фильтр по диапазону баланса
8. Сортировка
9. Удалить счёт
10. Сохранить данные
0. Выход
```

После выполнения каждого действия меню выводится снова.  
Программа работает в цикле до тех пор, пока пользователь не выберет пункт `0. Выход`.

### Реализованные пункты меню

| Пункт | Описание |
|---|---|
| `1` | Добавление накопительного счёта |
| `2` | Добавление кредитного счёта |
| `3` | Вывод всех счетов |
| `4` | Поиск счёта по номеру |
| `5` | Фильтрация только активных счетов |
| `6` | Фильтрация по валюте |
| `7` | Фильтрация по диапазону баланса |
| `8` | Сортировка счетов |
| `9` | Удаление счёта с подтверждением |
| `10` | Ручное сохранение данных |
| `0` | Выход из приложения с автоматическим сохранением |

## 4. Обработка ошибок ввода

В приложении реализована обработка некорректного пользовательского ввода.

Обрабатываются следующие ситуации:

- ввод строки вместо числа;
- выбор несуществующего пункта меню;
- ввод некорректного баланса;
- ввод некорректной процентной ставки;
- ввод некорректного кредитного лимита;
- попытка найти несуществующий счёт;
- попытка удалить несуществующий счёт;
- попытка добавить счёт с уже существующим номером;
- некорректный диапазон баланса при фильтрации.

Пример обработки ошибки:

```text
Выберите пункт: abc
Ошибка: введите число.
```

Пример обработки несуществующего пункта меню:

```text
Выберите пункт: 99
Ошибка: такого пункта меню нет.
```

Для ошибок предметной области созданы собственные исключения:

```python
class AccountNotFoundError(AppError):
    """Счёт не найден в коллекции."""


class DuplicateAccountError(AppError):
    """Счёт с таким номером уже существует."""


class InvalidAccountDataError(AppError):
    """Переданы некорректные данные банковского счёта."""


class StorageError(AppError):
    """Ошибка сохранения или загрузки данных."""
```

## 6. Сортировка

В приложении реализована сортировка с выбором стратегии.

Доступные стратегии сортировки:

```text
1. Имени владельца
2. Балансу
3. Валюте и балансу
4. Расчётному значению calculate()
```

Также пользователь может выбрать сортировку по возрастанию или по убыванию.

Пример:

```text
Сортировать по:
1. Имени владельца
2. Балансу
3. Валюте и балансу
4. Расчётному значению calculate()

Выберите стратегию: 2
Сортировать по убыванию? (y/n): y
```

## 7. Подтверждение опасных операций

Удаление счёта считается опасной операцией, поэтому перед удалением программа запрашивает подтверждение.

Пример:

```text
Введите номер счёта для удаления: SA1001

Будет удалён счёт:
Тип            | Номер      | Владелец             | Баланс       | Валюта | Активен  | Расчёт
-----------------------------------------------------------------------------------------------
Накопит.       | SA1001     | Иван Иванов          |      1500.00 | RUB    | да       |      1750.00

Удалить счёт SA1001? (y/n): y
Счёт SA1001 удалён.
```

При вводе `n` удаление отменяется:

```text
Удалить счёт SA1001? (y/n): n
Удаление отменено.
```
